## 与原前端方案的有意收缩

首版网址使用外链降级，不做任意 iframe。表格按固定版本查询快照，首版只有服务器翻页/排序/筛选/导出，没有无限滚动和所有过滤结果批量引用。图只显示/选择/局部拖动，不直接修改生产流程。Markdown 只读，以 Agent 新修订工具为扩展点，没有 WYSIWYG。创建会话由“开始新会话”显式执行，未做到首条消息提交时才懒创建。标签最多五个，没有完整多文档编辑器。

没有附件按钮，不以无法使用的按钮冒充已支持附件。会话输入待确认请求仅保存在当前 controller 内存中；刷新后的服务端历史仍在，但可靠离线发送箱尚未实现。

长期记忆变更时会清除该用户的 SDK 工作上下文，避免旧记忆继续注入；原始消息供用户查看，但当前没有从授权历史自动重建压缩上下文，因此恢复后的跨轮理解需要重新上下文工程。这是已知行为，不能描述为完整“遗忘且无损恢复”。
